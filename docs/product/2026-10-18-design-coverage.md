## 1. 如何理解完成状态

- **设计已定义**：功能目标、交互、异常及验收写入文档，不表示代码完成。
- **原型可操作**：本机浏览器可以验证交互或 localStorage 保存，不表示真实服务、权限或数据库可靠性完成。
- **演示**：题目、追问、反馈、连接或语音使用固定样例/确定性状态，不能作为用户真实能力或外部系统能力的证据。
- **待实施**：真实数据流、服务集成、版本、范围约束与正式验收需要后续工程完成。

本轮没有读取学习项目源码、调用云端模型、访问麦克风、启动 MCP 服务或写入语雀。原有逆向分析和课程输入测试保留，不重复执行。

## 3. 当前交互细节与限制

### 3.1 真实发生在浏览器内的操作

题库编辑和候选保存、用户提交文字、任务与成果、粘贴笔记、报告归档/笔记、Agent 配置及复习尝试会写入当前来源的 localStorage。清除浏览器数据会丢失；切换端口或打开 `file://` 不保证沿用同一数据。

报告归档复制当时的问题与回答；重开旧报告不替换当前活动面试。看过参考的回忆草稿保留辅助标记，下次新尝试可独立回忆。候选范围与成果交接复制输入内容，不直接修改原材料或原成果。

### 3.2 必须保留的差距

1. **生成与反馈**：候选题、追问、反馈、练习建议是固定样例，不会根据真实粘贴内容或用户回答推理。报告不输出伪精确能力总分。
2. **初始数据**：原型带 8 道示例题；正式初次使用题库应为空，示例独立体验。普通默认面试队列可能重复样例凑数；手选一道题已按一道练习，正式版仍要全面禁止静默重复。
3. **工作区**：两个示例空间共享材料池。项目路径只是显示关联，源码预览为示例；不存在真实文件权限、隔离或版本指纹。
4. **保存可靠性**：localStorage 不是事务数据库；现有保存函数没有完整确认机制和故障恢复，存储失败仍可能出现与真实写入不一致的成功提示。不能宣称 AC19 已完成。
5. **草稿**：回忆草稿主要在页面离开/其他保存事件留存，未达到停止输入后 800ms 的正式目标，也没有可靠的异常退出保证。
6. **导出**：Markdown 导出目前只有逐轮问题、回答和提示；新增报告笔记、完整反馈依据、来源未纳入，题库 JSON 导出尚缺。
7. **配置与工具**：Agent 提示词/工具选择只保存配置；MCP 连接、工具开关和调用状态只是界面演示，开关不代表系统权限，也没有实际受控执行。
8. **语音**：无麦克风、无音频上传，预设转写不代表识别质量；演示 30 秒计时不是正式 3 分钟录音上限。
9. **任务取消**：演示可停止本地计时，不能据此证明远端取消、迟到事件丢弃或副作用恢复。
10. **内容修订**：报告快照与输入快照不等于完整的不可变版本系统；缺题目/材料/配置版本、报告重生成比较及历史迁移。
11. **课程与其他入口**：课程转写关联、语雀、定时提醒、Skills 市场、自动操作电脑和通用代码执行没有实现；不在本轮设计完成状态里混记为真实能力。
12. **桌面发行**：目前为本机网页原型，尚无安装包、原生标题栏、系统凭据或 Windows 音频设备集成。

## 6. 输入与逆向证据边界

- [WorkBuddy 分析](../../analysis/workbuddy-5.8.3/README.md)：对应本地 5.8.3 发布包静态证据；功能映射用于自己实现，不等于其线上功能/完整内部执行循环已验证。
- [课程输入测试](../../analysis/szplayer-input-probe/README.md)：短片段音频得到用户确认，播放器窗口画面黑屏；没有解决课程原视频画面和时间映射。
- UI 中 `worker_tools.py`、`supervisor_agent.py` 和路径为关系示例，不是本轮对 `D:\python\tiangong_agent` 真实代码的结论。
- 文档不依赖重新运行 WorkBuddy、深造播放器或课程采集，也没有为了设计启动这些软件。

## 7. 后续工程建议顺序

1. **M1：建题真实流程**：最小桌面壳、本地 SQLite/密钥、工作区隔离/选文件、DeepSeek 适配、结构验证、保存与完整导出。
2. **M2：文字训练**：参数与题目版本、面试状态、依据回答追问、报告/复习、取消与恢复。
3. **M3：首版收口**：独立语音服务、麦克风、本地 stdio MCP、实际 Agent 配置权限、Windows 可读性与全验收。
4. **M4：课程复盘**：先验证独立课程材料与时间关联，再做小练习和语雀，避免受保护画面阻塞整个首版。

这是需求依赖顺序，不是已完成开发任务或工期承诺。[技术方案 v1.0](../technical/technical-design-v1.md)已补充技术栈、版本基线、语音适配选择、通信/数据契约与验收映射；依赖安装、账号可用性、识别质量及发行包兼容仍需真实验证。不为了复刻页面提前复制 WorkBuddy 的全部进程或引入复杂基础设施。
