## 打开方式

预览服务运行时访问 `http://127.0.0.1:8765/`。如服务已停，在 PowerShell 执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory 'D:\llm\agent\ai-workbench\prototypes\workbench-ui'
```

服务仅绑定本机。可直接打开 `index.html`，但推荐 HTTP 方式，使浏览器内的 localStorage 来源保持一致。更换地址/端口或清理浏览器数据会影响原型存档。

原型没有依赖构建步骤，无外部字体和模型请求；`index.html`、`app.js` 及四份本地 CSS 直接提供界面。

## 布局与页面

左侧全局共用新建任务、助理、专家·技能·连接器、定时任务、资料库、更多，下方任务历史、空间与设置。中央首页切换办公/开发/设计，只改变任务建议与提示，保留草稿、附件和空间。工作区选择放在输入区下方。

| 页面 | 本机地址/入口 | 当前可体验交互 |
| --- | --- | --- |
| 首页 | `/` | 三模块、任务输入、空间/访问方式、示例附件和建议任务 |
| 任务工作台 | `/?view=task-workbench` | 对话/计划、步骤/资料/成果页签、成果编辑保存、取消/失败/重试、中断恢复 |
| 资料库 | `/?view=workspace` | 来源预览、添加真实粘贴文本、选材并交给建题 |
| 题库整理 | 办公“面试题库”→整理 | 范围、数量、材料快照、演示生成、编辑与部分入库 |
| 面试题库 | `/?view=bank` | 岗位、主题、难度、关键词筛选；详情、编辑、选题面试 |
| AI 面试官 | 办公“AI 面试官”/题库选题 | 训练/模拟、文字/语音演示、提交、提示、追问、跳过、结束 |
| 面试报告示例 | `/?view=report-example` | 原回答/参考并置、提示统计、复盘笔记、加入复习 |
| 面试档案 | `/?view=reports` | 重开已归档的问题与回答，不替换当前活动面试 |
| 复习清单 | `/?view=review` | 未练/有记录筛选，先回忆后核对，自评并保留多次尝试 |
| Agent 中心 | `/?view=agents` | 两个内置流程，自定义名称/提示词/工具配置的创建与编辑 |
| 设置 | `/?view=settings` | 默认参数、模型/语音状态演示、MCP 工具开关/成功/超时文案 |
| 任务记录 | `/?view=tasks` | 按状态筛选、重开任务与已保存成果 |

开发/设计、助理、课程复盘、定时任务的入口表达信息架构或建立任务草稿，没有因此新增通用编程执行、设计生成、语雀写入和后台调度能力。

## 推荐体验顺序

1. 进入资料库，预览一份示例源码；添加一段自己的文字笔记并选中。
2. 用所选资料进入整理，确认范围，生成演示候选题；编辑一题，只保存部分候选。
3. 回题库筛选、查看要点与来源，手选一道题开始单题训练。
4. 输入自己的解释并提交，回看原回答，体验提示和固定追问；也可切换演示语音，核对预设转写后主动提交。
5. 结束并查看报告，保存复盘笔记，加入复习；从面试档案重开确认原回答仍在。
6. 在复习清单开始回忆，先写理解再展开参考；记录是否借助参考和自评。下一次仍可练，不自动判永久掌握。
7. 回任务示例编辑成果，主动保存；“进入题库整理”会把当前成果复制为新任务的输入快照。
8. 打开设置和 Agent 中心，体验默认参数、自定义配置编辑和工具状态演示。

## 交互约定

- 任务工作台的检查区可收起；宽度不超过 1020px 时上下排列，点击成果/检查区入口会定位过去。
- 资料预览与选入任务分开；待核对示例不可选。原型笔记标题必填、最长 80 字符，内容必填、最长 20,000 字符。
- 题库筛选结果与详情一致，零结果不显示旧题；手选单题只安排一题。普通默认示例队列仍可能重复凑预设题数，正式版需修正。
- 成果切页签不丢编辑，保存后本地留存；续聊追加要求，不直接覆盖手改内容。原型不真实解析 Markdown 生成新题。
- 新面试保存追问上限；修改默认值不改变已开始轮次。报告归档快照与当前面试分开。
- 报告笔记明确保存；回忆草稿保存依赖离开/其他保存事件，尚未达到正式版 800ms 保存目标。
- 自定义 Agent 配置能保存和重新编辑；工具开关只表达设计，不能赋予系统权限。

## 演示边界与已知缺口

- 候选题来自内置样例，生成进度确定；没有实时 DeepSeek 输出，也不根据粘贴笔记真实生成题目。
- 用户提交文字会被记录，追问、反馈与练习建议是固定示例，不会实际评估能力。报告不提供真实能力评分或招聘通过率。
- 语音不访问麦克风、不采集/上传音频，转写是预设文字；演示录音最多 30 秒，正式设计上限为 3 分钟。
- 未读取或上传 `D:\python\tiangong_agent`；项目路径和源码预览用于表现关联。两个示例空间仍共用材料池，未完成真实工作区隔离。
- 模型/MCP 测试只变更演示状态，不发网络请求或启动工具进程。密钥输入禁用，勿输入真实凭据。MCP 开关没有持久化或实际执行权限控制。
- localStorage 保存题库、笔记、配置、回答、报告/复盘笔记、复习尝试及任务/成果。不是正式 SQLite、系统密钥或后台服务，存储故障和恢复尚未可靠实现。
- 简版 Markdown 仅导出逐轮问题、回答与提示；新笔记、完整反馈/来源和题库 JSON 尚未纳入。
- 正式文件解析、版本、幂等、真实取消/重试、服务异常、权限边界和桌面发行，均按 PRD 后续实现。
